# PlantNow

واجهة عربية لعرض معلومات زراعية موثقة عن السودان، مع تحديد المنطقة وعرض خيارات أولية للمحاصيل.

## تشغيل محليًا

يتطلب Ruby وJekyll. من مجلد المشروع شغّل:

```sh
jekyll serve --baseurl "" --host 0.0.0.0 --port 3000
```

ثم افتح `http://localhost:3000`.

لبناء الموقع إلى `_site/`:

```sh
jekyll build
```

وعند اختبار نشر الموقع تحت مسار مستودع مثل GitHub Pages:

```sh
jekyll build
```

المجلد `_site/` ناتج بناء؛ مصدر الموقع هو ملفات HTML وCSS وJavaScript وبيانات `data/`.

## تحديد الموقع والمحاصيل

- يتطلب تحديد الموقع إذنًا صريحًا من المستخدم واتصالًا بالإنترنت، ويعمل عبر `localhost` أو HTTPS.
- يستخدم التطبيق Nominatim للتعرف على اسم المنطقة، وخرائط OpenStreetMap، وNASA POWER لعرض ملخص مناخي تاريخي.
- لا تُرسل الإحداثيات إلا بعد الضغط على زر تحديد الموقع. تخضع خدمات OpenStreetMap لسياسات الاستخدام الخاصة بها، وقد تتغير أو لا تتوفر.
- خيارات الحبوب والشتول والأشجار المثمرة استرشادية وليست تصنيفًا زراعيًا معتمدًا. لا يحلل التطبيق التربة ولا يتنبأ بظروف الموسم الحالية؛ ينبغي التحقق من التربة والري والموسم محليًا.

## بيانات ومصادر السودان

البيانات المعروضة ومرجعها موجودة في [`data/sudan/agriculture-snapshot.json`](data/sudan/agriculture-snapshot.json). تتضمن المصادر الفاو، وFAO GAEZ، وISRIC SoilGrids، وNASA POWER، وOpenStreetMap. تُعرض التواريخ والنطاقات المتاحة لتجنب اعتبار المؤشرات الوطنية نصيحة محلية.

## النشر

يحتوي المستودع على سير عمل GitHub Actions في [`.github/workflows/jekyll-gh-pages.yml`](.github/workflows/jekyll-gh-pages.yml) يبني الموقع وينشره إلى GitHub Pages عند الدفع إلى `main`، إذا كان GitHub Pages مضبوطًا لاستخدام GitHub Actions في إعدادات المستودع.
